# Refine an issue

Refine the GitHub issue named by the user.

1. Read the issue with `gh`. Inspect relevant code, read or fetch docs, history, and related issues or pull requests.
2. Separate facts, assumptions, decisions, and open questions.
3. Ask focused questions for every unresolved requirement or scope decision. Wait for answers before finalizing.
4. Produce a concise refinement with:
   - Problem
   - Goal
   - Scope and constraints
   - Requirements
   - Acceptance criteria
   - Open questions

Do not edit code or the issue unless the user asks.
