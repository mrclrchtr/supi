# Prompt suggestions replace the editor component

`@mrclrchtr/supi-prompt-suggestions` installs a package-owned `GhostTextEditor` via PI's `setEditorComponent` during each `session_start`, rather than wrapping PI's currently configured editor component. This replacement keeps the feature boundary small: the package owns ghost-text rendering, right-arrow acceptance, dismissal behavior, history reseeding, and app-keybinding inheritance through `CustomEditor` without needing a fragile generic adapter for arbitrary custom editors.

The trade-off is editor composition: another extension that also replaces the editor may be overwritten depending on load order. That is acceptable for the current package because prompt suggestions are an optional quality-of-life feature, PI's custom-editor composition contract is factory-based rather than decorator-based, and wrapping arbitrary editors would add complexity without an immediate requirement. If editor composition becomes a real user need, it should be redesigned explicitly rather than partially approximated.

Replacing the editor creates a fresh editor instance on reload and session replacement, so in-memory editor history is re-seeded from persisted user messages on the active session branch. Ghost text is accepted via Right Arrow (inserts text without submitting). Escape dismisses the ghost suggestion and is consumed; a later Escape after ghost text is gone reaches PI's normal interrupt/double-escape behavior. Typing any character dismisses the ghost suggestion before the character is processed. Ghost text is rendered using dim styling for visual distinction from entered text.
