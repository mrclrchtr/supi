# Bound delegation output in two lanes

> **Status: Amended (2026-08-14).** The joined parent-facing result now has one aggregate model-output bound in addition to the per-task lane caps below.

Each task contributes at most 16,000 characters of final text to the parent model, while tool details and the viewer retain at most 50 KB per task for expanded Markdown; both lanes disclose truncation. The joined parent-facing result has one aggregate bound of 2,000 lines or 51,200 UTF-8 bytes, whichever is reached first. Every task header and status remains visible; when the aggregate bound applies, visible space is allocated fairly with redistribution of unused shares, shortened sections carry exact truncation markers, and the complete joined per-task model-lane text spills to a private OS temporary file. This bounds four-way orchestration context without adding a continuation tool or persistent history, while preserving more human-inspectable output than the model-facing lane can safely carry.
