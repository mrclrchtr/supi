# supi-settings

Configuration surface for SuPi: the `/supi-settings` command that renders registered Settings Modules. Drives the TUI for inspecting and editing scoped values with source-aware inheritance.

See also: `packages/supi-core/CONTEXT.md` (Settings Contribution, Settings Module, Config Settings Definition, Project Override, Explicit Value, Inherited Value, Inheritance Source, Value Source State, Inherit Action, Reset to Default Action, Unset Action) and root `CONTEXT.md` (Configuration Surface).
