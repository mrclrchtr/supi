# supi-settings

Configuration surface for SuPi: the `/supi-settings` command that renders registered settings sections. Drives the TUI for inspecting and editing SuPi config values with scope-aware inheritance.

See also: `packages/supi-core/CONTEXT.md` (Configuration Section ID, Settings Contribution, Declarative Settings Schema, Project Override, Explicit Value, Inherited Value, Inheritance Source, Value Source State, Inherit Action, Reset to Default Action) and root `CONTEXT.md` (Configuration Surface).
