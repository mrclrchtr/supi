# Lease Prepared Review Plans

A Prepared Review decision is normalized and validated before its Review Plan is leased. A lease rejects concurrent execution without destroying the plan. When at least one Review Task returns a structured submission, the plan is consumed; when every task fails, times out, or is canceled, the lease is released and the same plan may be retried. Invalid decisions never acquire a lease. This avoids destructive input errors and all-provider failures while preventing duplicate execution of already-completed tasks. Repository stability remains a caller precondition across retries.
