# Lease Prepared Review Plans

A Prepared Review decision is normalized and validated before its Review Plan is leased. A lease rejects concurrent execution without destroying the plan. Before reviewers start, execution re-materializes the target and compares it with the plan's exact Review Snapshot; drift invalidates the plan and requires preparation again. Otherwise, when at least one Review Task returns a structured submission, the plan is consumed; when every task fails, times out, or is canceled, the lease is released and the same plan may be retried in a fresh Review Workspace. Invalid decisions never acquire a lease. This avoids destructive input errors and all-provider failures while preventing duplicate execution of already-completed tasks.
