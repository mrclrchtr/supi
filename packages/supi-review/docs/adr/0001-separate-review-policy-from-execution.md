# Separate caller-owned review policy from Review Engine mechanics

Callers define review methodology as one or more Review Tasks containing a stable id and freeform instructions. The Review Engine owns target resolution, Review Workspace materialization, the Inspection-only protocol, canonical packet construction and hashing, child-session execution, the fixed result grammar, and per-task verdict derivation; callers cannot replace those mechanics. Each task outcome records the SHA-256 of its exact packet bytes. `/supi-review` may use an advisory Planner Draft, which the user can edit or discard before execution.
