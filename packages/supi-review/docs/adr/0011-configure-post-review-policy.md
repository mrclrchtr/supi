# Configure the containing Agent's post-review policy

Use one scoped `review.postReviewPolicy` setting for both interactive and agent-initiated completed reviews when the user has not given a direct Post-Review Disposition; its values are `ask`, `verify`, `verify-and-fix`, `fix`, and `report`, with `ask` as the default. Ask offers verification, verification followed by fixing, fixing all or selected findings, or reporting; Verify asks again after independently confirming or refuting findings, while both fixing policies act on all applicable findings, including findings from completed tasks in a partial batch. This remains a prompt-level containing-Agent protocol outside the Review Engine: no findings trigger no extra command turn, `/supi-review` with `report` remains terminal, complete paged output must be read before action, conflicting or stale findings are re-verified against live code, and non-trivial fixes use an existing targeted check when available.
