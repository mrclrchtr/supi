# Account for child-model usage

Every isolated child run aggregates the complete Pi `Usage` records from its assistant turns, preserving cache, reasoning, token, and cost fields. Reviewer usage is attached to each Review Task and summed into `supi_review_run`; successful interactive Planner usage is recorded with the final `/supi-review` result. Failure and cancellation outcomes retain partial usage when available. The interactive slash-command renderer displays usage, but Pi currently provides no usage field for custom messages, so command-originated child usage cannot contribute to Pi's session accounting without an upstream API.
