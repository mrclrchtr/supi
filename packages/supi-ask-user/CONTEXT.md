# supi-ask-user

Rich questionnaire UI for structured agent-user decisions in PI. Renders multi-question forms with choice and text inputs, driven by typed question schemas.

See also: root `CONTEXT.md` for project-wide terms.

## Language

**Structured Decision**:
A fixed-form agent-user interaction used when the agent needs a focused choice or short answer before it can continue. It should be described concretely rather than as a vague handoff.
_Avoid_: clearer handoff
