# Changelog

## [11.5.0]

- `ask_user` now declares read-only tool annotations, so permission extensions that read `pi.getAllTools()` do not ask for confirmation before showing a form ([#582](https://github.com/mrclrchtr/supi/issues/582)).

## [11.4.0]

- Overlay forms now report Pi as waiting for your answer on terminals that show program status, like inline forms.

## [11.3.0]

- Added package-specific release notes for structured questions and reusable decision forms.
